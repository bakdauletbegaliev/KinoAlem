# 🎬 KinoAlem

KinoAlem is a responsive movie website dedicated to Kazakh cinema. The project was created as a university assignment to demonstrate HTML5, CSS3, Bootstrap, and responsive web design skills.

## 🌐 Live Demo

Website: https://bakdauletbegaliev.github.io/KinoAlem/

GitHub Repository:
https://github.com/bakdauletbegaliev/KinoAlem

## 📌 Features

- Responsive design for desktop, tablet, and mobile devices
- Bootstrap navigation bar
- Movie catalog
- Individual movie detail pages
- Embedded YouTube trailer modal
- Genre filtering using pure CSS
- Contact form
- Movie information tables
- Modern dark-themed interface

## 🛠 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Responsive Design
- CSS Grid
- Flexbox

## 📄 Website Pages

- Home
- About
- Movies
- Contact
- Movie Details (91)
- Movie Details (Shal)
- Movie Details (Zamanback)

## 📱 Responsive Design

The website includes:

- Bootstrap Grid System
- Bootstrap Utility Classes
- Media Queries for tablets and mobile devices

## 📷 Main Functionality

- Browse Kazakh movies
- View detailed information
- Watch official trailers
- Filter movies by genre
- Contact page with a feedback form
